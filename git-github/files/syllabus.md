## A fill in the blanks class

### Policies

This class is intended for you, the learner, to create your own aventure. So there is no plan laid out. It is up to you, and it's something you can do.

You inventory for this class can include:

- maps
- a backpack
- snacks
- books
- utensils
- clothing

As long as they:

1. Support your learning.
2. Are something you can reasonably carry with you for the duration of the class.

**You  should aim to fit everything from your inventory inside of one item.**
