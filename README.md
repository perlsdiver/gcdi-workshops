# gcdi-workshops

Workshops for Graduate Center Digital Initiatives.

This repository hosts materials for several skills workshops.

## Workshops

- Intro to Git and GitHub
- Additional workshops can be added over time

## Intro to Git and GitHub workshop activity

Participants contribute to a curated list of interesting repositories:

- File: `/workshops/git-github/interesting-repos.md`

During the workshop, each participant should:

1. Add one repository to the list.
2. Include a short note about why it is interesting.
3. Open a pull request with the change.
