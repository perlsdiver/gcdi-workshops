# gcdi-workshops
A repository consisting of digital skills workshops for Graduate Center Digital Initiatives, authored and adapted by Ian G. Williams. This is a sandbox space to test out workshops before refining them integrating them them into the [GCDigitalFellows organization](https://github.com/orgs/GCDigitalFellows/).

These are work in progress workshops that will be further refined and integrated into GCDF's repository.

Current workshops:

- A Scholar's Introduction To Git and GitHub
